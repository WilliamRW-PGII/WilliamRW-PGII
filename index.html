C++ Console Game

Dungeon Exploration Simulator

Dungeon Exploration Simulator is a text-based C++ game where the player explores a 3x3 dungeon while fighting enemies, avoiding traps, collecting useful items, and preparing to defeat the Dungeon Guardian. The project was developed across multiple milestones and expanded as I learned new programming concepts.

Key Features

  • 3x3 dungeon with movement and room exploration tracking
  • Turn-based combat with multiple enemies and randomized damage
  • Inventory system with healing potions, weapons, and treasure
  • Traps, gold collection, player statistics, and a final boss encounter
  • Object-oriented design using Game, Player, Room, Enemy, and Item classes

What I Learned

This project helped me become more comfortable organizing a larger C++ application across multiple classes and files. One of my biggest challenges was keeping the different gameplay systems connected without creating duplicate code. Refactoring the room-entry logic and separating responsibilities between functions helped make the project easier to understand, test, and maintain. I also gained more experience using GitHub Issues, branches, commits, milestones, and pull requests to manage development.
